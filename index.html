🎮 How to Play

① Select a jewel.
② Select an adjacent jewel (up, down, left, or right) to swap.
③ Match 3 or more jewels in a row to score points.

Special Jewels
Match 4 to create a line-clearing jewel. Match 5 or more to create a jewel that clears nearby gems.
